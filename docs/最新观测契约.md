# `glof.core.latest` 契约（冻结版）

所有并行开发都以本文件为准。**改契约要先改这里**，不要在实现里悄悄改。

## 公开 API

```python
from glof.core.latest import LatestObservation, fetch_latest

obs: LatestObservation | None = fetch_latest(
    bbox,                      # (lon_min, lat_min, lon_max, lat_max)，WGS84
    *,
    lookback_days: int = 20,   # 往前检索多少天
    max_cloud: float = 20.0,   # 整景云量上限（%）
    min_area_km2: float = 0.01,
    today: date | None = None, # 基准日期；测试必须显式传
    progress: Callable[[str], None] | None = None,
)
```

`fetch_latest` **不抛异常**。检索失败、无可用影像、全部候选不合格都返回 `None`。

## `LatestObservation` 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `observed_on` | `str` | 影像拍摄日期 `YYYY-MM-DD`（不是下载日期） |
| `age_days` | `int` | 距今多少天。**界面必须显示**，这是本功能诚实性的核心 |
| `scene_id` | `str` | 场景 ID，可回溯 |
| `tile` | `str` | 瓦片号，如 `T43SFV` |
| `cloud` | `float` | 整景云量 % |
| `coverage` | `float` | 窗口覆盖率 0–1，低于 `MIN_COVERAGE_FRAC`(0.95) 的候选不会被采用 |
| `records` | `list[LakeRecord]` | 湖泊，按面积降序 |
| `total_area_km2` | `float \| None` | 总面积。**`None` = 没量到，不是 0** |
| `largest_area_km2` | `float \| None` | 最大单湖面积。同上 |
| `ndwi_max` | `float` | 窗口内 NDWI 最大值，解释"为什么没量到"的旁证 |
| `season_warning` | `str` | 非消融期提示，空串表示无异常 |

## 只读属性

| 属性 | 说明 |
|---|---|
| `n_lakes` | `len(records)` |
| `is_frozen` | 窗口内无水信号（`ndwi_max < 0.05`） |
| `usable` | `total_area_km2 is not None`，能不能拿来判"现在湖多大" |

## 三条不可违背的语义

1. **`None` 不是 0**。冰封、云遮、数据不可用时 `total_area_km2` 必须是 `None`。
   返回 `0.0` 会被下游当成"量到了且湖是空的"。
2. **`fetch_latest` 返回 `None` 表示"暂无可用观测"**，不是"没有湖"。
   调用方必须区分这两种情况来措辞。
3. **判水口径固定取自 `timeseries`**（`NDWI_THRESHOLD=0.02`、`NIR_MAX=0.20`、
   `SNOW_NDSI_THRESHOLD=0.4`），不在本模块暴露阈值参数。当前面积必须能与历史
   序列直接比较，否则这个功能没有意义。

## 名字

对外一律叫「最新可用观测」，**不要叫"实时"**。理由见 `docs/命名说明.md`：
Sentinel-2 重访 5 天 + L2A 处理 1–3 天，叫实时是承诺做不到的事。

## 已知的数据质量坑（实测 2026-11-02）

2026-10-28 的 `T43SFV` / `T43SGV` 两景，AOI 窗口内：

* SCL 中位数 = 11（SNOW/ICE），整窗被雪覆盖
* B03/B08/B11 反射率中位数都是 0.0128，min/max 恰好 0/255，等于 0–255 的均匀噪声
* 直接跑 NDWI 会得到 36.4 km² 的"湖"，而窗口总共才 36 km² —— 整窗都是假水

对照：2024-08-14、2025-09-13 的正常景，窗口内 B03/B08 中位数在 3000–4200 DN
（即反射率 0.30–0.42）。

所以 `fetch_latest` 必须有数据质量闸门，不能只看云量。合格景的窗口 NIR 中位数
远高于 0.05（雪 0.6–0.9、岩 0.25–0.45、植被 0.25+），只有水面才会低于 0.05，
而整窗是水在冰川谷地里不可能发生。
